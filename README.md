# Cloud-Based Multi-Tenant SaaS Project Management Platform

## Project Description

The Cloud-Based Multi-Tenant SaaS Project Management Platform
is a web-based application designed to manage projects,
team members, and completed tasks through a centralized dashboard.

The application is developed using Python Flask and deployed
using Docker containers.

## Technologies Used

- Python
- Flask
- HTML
- CSS
- Git
- GitHub
- Docker
- Docker Compose

## Project Features

- Project management dashboard
- Total project statistics
- Team member statistics
- Completed task statistics
- Available project listing
- Docker container deployment
